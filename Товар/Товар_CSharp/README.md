# Товар

Учебное приложение для продажи товаров на C# и Windows Forms.
Автор курсового проекта: Богомолов Дмитрий Алексеевич, группа 25-КБ-ПИ2.

## Запуск

Откройте bin\TovarSales.exe двойным щелчком.
Нужны Windows и .NET Framework 4.8 или более новая совместимая версия.
Visual Studio для запуска не требуется.

## Исходники и сборка

Откройте TovarSales.sln в Visual Studio 2022. Для редактирования нужна рабочая нагрузка «Разработка классических приложений .NET» и пакет разработки .NET Framework 4.8.

В обозревателе решений выберите MainForm.cs и нажмите Shift+F7 или «Просмотреть конструктор». Вкладки каталога, корзины и отчета доступны в конструкторе. Для других окон откройте ProductForm.cs или ReceiptForm.cs тем же способом. Выберите элемент мышью, чтобы переместить его или изменить свойства. Сохраните форму и нажмите F5.

Каждой форме соответствуют файл .cs с обработчиками действий, файл .Designer.cs с элементами окна и файл .resx для ресурсов. Модели, работа с XML и точка входа находятся в Program.cs. Контрольные примеры находятся в Tests.cs. Для сборки из командной строки можно использовать build.cmd.

## Пример из курсовой

1. При первом запуске в каталоге находятся пять товаров со скриншота.
2. Выберите «Тетрадь 48 листов», укажите количество 2.
3. Нажмите «Добавить в корзину». Итог составит 130,00 руб.
4. Нажмите «Оформить продажу». Откроется состав покупки.
5. В каталоге останется 38 тетрадей.
6. На вкладке «Продажи и отчет» нажмите «Показать».
7. Продажу можно открыть повторно или выгрузить отчет в CSV.

Пример начинается с нового набора данных. При последующих запусках сохраняются ваши товары и продажи.
Дата продажи берется с часов компьютера.

## Что реализовано

F01: создание и изменение карточки товара.
F02: поиск по названию и категории без учета регистра, архивирование.
F03: корзина с объединением одинаковых товаров и проверкой общего количества.
F04: удаление строки и очистка корзины без списания товара.
F05: оформление продажи и уменьшение остатка после успешной записи.
F06: история с исходными названиями и ценами на момент покупки.
F07: отчет о выручке за период, включая обе граничные даты.
F08: экспорт номера, даты и суммы продаж в CSV.

Ограничения полей: название до 100 символов, категория до 50, цена от 0,01 до 1 000 000 рублей, остаток от 0 до 1 000 000 штук.
После изменения названия или цены товара соответствующую строку корзины нужно удалить и добавить заново.
При изменении остатка оформление повторно проверяет доступное количество.

## Данные

Основной файл: %LOCALAPPDATA%\TovarSales\store.xml
Предыдущая версия: store.xml.bak в той же папке.
Временный файл: store.xml.tmp.

Программа записывает во временный XML сразу продажу и новые остатки, сбрасывает запись на накопитель через Flush(true), затем заменяет основной файл.
Рабочий набор обновляется после успешной файловой операции.
При ошибке записи сохраняются прежние данные и корзина.
Поврежденный XML не заменяется демонстрационными товарами.

Для ручного восстановления закройте приложение, сохраните отдельную копию поврежденного файла, затем скопируйте store.xml.bak под именем store.xml.
Для дополнительной резервной копии при закрытой программе скопируйте store.xml в другую папку или на другой накопитель.

Корзина хранится в памяти и при закрытии приложения теряется.
Одновременный обычный запуск двух экземпляров в одной пользовательской сессии блокируется Mutex.

## Расчеты и структура

Сумма строки: A = p × q, где p - цена, q - количество.
Итог покупки: S = сумма всех A.
Выручка: сумма итогов продаж за выбранный период.

Product: код, название, категория, цена, остаток и признак активности.
SaleItem: код товара и сохраненные название, цена и количество.
Sale: номер, дата, список строк и рассчитанный итог.
StoreData: список товаров и список продаж.
Store: проверка, копирование и сохранение данных.
MainForm: вкладки каталога, корзины и отчета.
ProductForm: карточка товара.
ReceiptForm: окно состава продажи.

Названия классов, методы Checkout, Copy и Save, порядок сохранения и формулы соответствуют приложению Б.
Перенос строки внутри сообщения об изменении цены из документа исправлен для компиляции.
Поиск товара в Checkout записан обычным циклом вместо Find с лямбда-выражением.

## Проверки

В PowerShell из папки проекта:

    $p = Start-Process .\bin\TovarSales.exe -ArgumentList '--test' -PassThru -Wait
    $p.ExitCode

Режим --test создает отдельную новую папку TovarSalesTest_* во временной папке Windows.
Результат записывается в results.txt внутри нее. Код завершения 0 означает успех.

Для сохранения результатов в выбранную новую пустую папку без пробелов:

    $p = Start-Process .\bin\TovarSales.exe -ArgumentList '--test','C:\Temp\TovarCheck01' -PassThru -Wait
    $p.ExitCode

Проверка окон:

    $p = Start-Process .\bin\TovarSales.exe -ArgumentList '--ui-test','C:\Temp\TovarUiCheck01' -PassThru -Wait
    $p.ExitCode

Режим --ui-test проверяет формы в отдельном наборе данных, нажимает кнопки программно и создает PNG-изображения форм через DrawToBitmap.
Он не меняет рабочий store.xml в профиле пользователя.
Передавайте новую пустую папку для каждого запуска.

Проверено при подготовке: 22 группы проверок логики, включая T01-T11 из таблицы 6, и 6 групп проверок интерфейса.
Подробные результаты находятся в папке Проверки.
Изображения в ней получены рендером работающих форм, а не снимком рабочего стола.

## Границы проекта

Программа предназначена для одного рабочего места и учебного учета.
Регистрации, разделения ролей, базы данных, возвратов, банковской оплаты и подключения кассы нет.
Окно продажи содержит учебную запись, которая не является фискальным чеком.
